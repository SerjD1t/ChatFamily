# Итерация 1: серверное ядро (архив)

Документ сохранён как историческая запись. Указанные в нём последующие задачи реализованы в более поздних версиях; актуальные планы находятся в [ROADMAP.md](ROADMAP.md).

Готово:

- конфигурация через переменные окружения;
- защищённая HMAC-сессия в `HttpOnly` cookie;
- категории прав;
- общий чат и создание групп пользователями с правом `create_groups`;
- история в рамках работающего процесса;
- редактирование и мягкое удаление только автором;
- HTTP API и тесты ключевых правил.

Следующая итерация заменяет временное хранение в памяти на PostgreSQL, добавляет приглашения, личные диалоги, файлы/фото и WebSocket. До этого перезапуск сервера очищает тестовые данные.
