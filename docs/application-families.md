# Управление всеми семьями

Опубликовано 2026-09-17, runtime `chatfamily-app:20260917-global-families`.

Администрирование приложения → Семьи. Требуется глобальное право `manage_application`; роль администратора одной семьи его не заменяет.

- Поиск по названию и страницы по 25 семей. В каждой строке название, число участников, владельцы; число включает деактивированные аккаунты. Архивные семьи видны, но доступны только для просмотра.
- В карточке семьи: переименование (также меняет название общего семейного чата), поиск участников, отдельное окно роли/категорий/статуса.
- Добавление уже зарегистрированного активного пользователя через поиск по имени и фамилии и подтверждение. Он получает доступ к общему семейному чату и его истории; в отдельные группы автоматически не добавляется.
- Администратор приложения может назначать владельцев/администраторов/участников, не вступая в семью. Владельцев может быть несколько. Для передачи управления сначала назначить нового активного владельца, затем понизить прежнего. Последнего активного владельца нельзя понизить или исключить.
- Исключение требует подтверждения, удаляет членство во всех чатах данной семьи и категории, аннулирует ещё не принятые приглашения этого пользователя в семью. История сообщений, аккаунт и личные диалоги остаются. Повторное добавление существующего участника не перезаписывает его роль; повторное исключение безопасно.

Управление не даёт автоматического доступа к сообщениям, вложениям и делам чужой семьи. Для вступления самого администратора применяется то же явное добавление с подтверждением. Функций удаления/архивирования семей и чтения их переписки в этом разделе нет.

## Реализация и проверки

Отдельные маршруты `/api/v1/application/families`: GET списка; GET `/{familyID}/members` и `/candidates`; PATCH названия семьи; PUT/PATCH/DELETE участника `/{familyID}/members/{userID}`. В запросах списков `q` и `offset`, размер страницы 25. Ответы — private, no-store. Глобальные права проверяются обработчиком и по актуальной записи БД; мутации повторно проверяют их внутри транзакции. Семейные роли не расширены до глобальных прав.

Изменения членства и ролей через обычную и глобальную формы используют общую блокировку строки семьи и транзакцию: два одновременных понижения владельцев не оставляют семью без владельца. Ошибки не стирают ввод, повторные нажатия во время запроса блокируются. Поиск и постраничная навигация не меняют текущую семью/историю чата.

Миграций и нового APK не требуется. Go-тесты, 35 web-тестов и интеграционная проверка на отдельной БД выполнены; после публикации проверены HTTPS, ресурсы и отказ всех новых API без авторизации. Проверять вручную диалоги и клавиатуру на Android/Safari, длинные имена, узкий экран и RU/EN.
