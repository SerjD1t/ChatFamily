# Независимые группы

Развёрнуто 2026-09-19 вместе с межсемейными чатами: runtime
`chatfamily-app:20260919-interfamily`, PostgreSQL, миграции 030–031.

## Состав и права

Любой активный пользователь может создать группу, даже без семьи. Создатель —
единственный владелец. Группа имеет собственный состав, независимый от семей.

| Действие | Владелец | Администратор группы | Участник |
|---|---|---|---|
| Читать и писать, отправлять вложения | Да | Да | Да |
| Добавлять пользователей чата | Да | Да | Только с разрешением |
| Менять название и пиктограмму | Да | Да | Нет |
| Исключать обычных участников, менять разрешение приглашать | Да | Да | Нет |
| Назначать/снимать администраторов | Да | Нет | Нет |
| Передавать владение, архивировать группу | Да | Нет | Нет |
| Выйти из группы | После передачи владения | Да | Да |

В меню участников группы открываются настройки, добавление и отдельный редактор
участника. Пиктограмма выбирается из набора; файлы-картинки не загружаются.
Владелец и администраторы всегда могут приглашать; персональное разрешение нужно
для обычных участников. Администратор не может исключить другого администратора
или владельца. Передавший владение остаётся администратором.

Добавление происходит сразу, без запроса согласия получателю, как раньше:
новый участник получает всю историю. Интерфейс предупреждает об этом.
Исключение/выход закрывают серверный доступ, но не удаляют историю. Уже скачанные
копии файлов или прочитанные сообщения отозвать с устройства невозможно.

Роли семьи и право администрирования приложения не дают доступ к группе.
Изменения состава и ролей сериализованы блокировкой строки группы в транзакции.
Клиенты обновляют список и права без полной перерисовки сообщений; при утрате
членства закрывают открытый чат. Смена семьи сохраняет открытый групповой чат.

## Разделы навигации

- **Семья**: общий чат под названием выбранной семьи и группы, все участники
  которых входят в эту семью. Членство проверяется по всем участникам группы.
- **Семейные чаты**: отдельные [чаты между двумя семьями](interfamily-chats.md) с подтверждением обеих сторон и явным составом.
- **Группы**: остальные независимые группы пользователя.
- **Личные**: глобальные личные диалоги, без изменений.

Группа отображается только в одном разделе. Если состав принадлежит нескольким
семьям, используется выбранная семья. Добавление внешнего участника или выход
из семьи меняет только раздел; доступ к группе не меняется. Предопределённые
пункты «Дети» и «Бабушки и дедушки» убраны, категории участников сохранены.
Пиктограмму общего семейного чата меняет владелец/администратор этой семьи.

## Существующие данные и восстановление

Миграция 030 сохраняет идентификаторы, сообщения, файлы и состав старых групп,
снимает family_id и назначает владельцем created_by. Старые семейные права
не преобразуются автоматически в права администратора группы.

Если создатель отсутствует, отключён или уже вышел, он не добавляется обратно.
В администрировании приложения есть «Восстановить владельца группы»:
можно назначить активного текущего участника. Администратор приложения не
становится участником и не получает переписку. Для группы без активных участников
необходимо отдельно согласованное восстановление данных; кнопка назначения
недоступна. Замена действующего активного владельца таким способом запрещена.

Перед развёртыванием нужны резервная копия и проверка миграции. Старый сервер,
ожидающий family_id у групп, несовместим с новой моделью: простой откат образа
не подходит. Использовать исправленный совместимый образ; восстановление старой
БД допускается только отдельным согласованным процессом с учётом новых сообщений.

## Чаты между семьями

Реализован отдельный тип беседы с подтверждением обеих сторон и явным выбором
представителей. См. [инструкцию](interfamily-chats.md). Это не автоматическая
классификация произвольной группы; семейные связи и права хранятся отдельно.
