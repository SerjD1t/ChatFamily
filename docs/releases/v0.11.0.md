# ChatFamily v0.11.0

## Оформление и навигация

- Скины «Семейный» и «Классический», системная/светлая/тёмная/контрастная палитра.
- Плотность интерфейса и размер текста 13/16/21 CSS px при стандартном корневом размере; сохранение отдельно для аккаунта на устройстве, предпросмотр и отмена. Сенсорные области нажатия не уменьшаются вместе с текстом.
- «Дела и покупки» открываются со списка: добавление и поиск раскрываются по запросу на desktop и телефоне; черновики и фильтры сохраняются.
- Исправлено открытие личных диалогов для пользователей без семьи: приглашение создать семью больше не скрывает сообщения.

## Семьи и прочтение

- Краткий список участников семьи с отдельным редактором вместо массового выбора и сохранения всех строк.
- Администратор приложения видит все семьи, число участников, владельцев и может управлять названием, составом, ролями, категориями и статусом через отдельные формы с поиском и серверной пагинацией.
- Эти права не предоставляют автоматическое членство или доступ к чужой переписке, вложениям и делам. Последний активный владелец защищён от удаления/понижения, включая одновременные запросы.
- Галочки собственных сообщений открывают сведения о доставке/прочтении по получателям и времени. В группах используется текущий состав, не исторический список.
- Семейные подписи отображаются как «Статус (Имя)», без фамилии. Миграция 025; прежние цитаты в тексте сообщений не переписываются.

## Вложения и хранилище

- Миниатюры изображений, первого кадра видео и первой страницы PDF; остальные форматы остаются иконками.
- Отдельное обслуживание серверного хранилища: статистика, настройки миниатюр, анализ перед очисткой, карантин неиспользуемых загрузок и восстановление из него.
- Управление локальным кэшем Android при наличии соответствующей capability оболочки; очередь неотправленных вложений не очищается вместе с кэшем.

## Резервные копии — требуют отдельного включения

- Автономная служба VPS и административный раздел: интервал, часовой пояс, лимит объёма, состояние, ручной запуск и история.
- Шифрование и дедупликация restic; Яндекс Диск только с доступом к папке приложения. Секреты не передаются веб-интерфейсу.
- Прогрессивное хранение: все свежие копии, затем одна за день/неделю/месяц/год. Старые точки удаляются только после успешной новой копии и проверки.
- Согласованный снимок PostgreSQL и originals кратко останавливает app; загрузка в облако идёт после возобновления. Плановая стадия снимка ограничена 180 секундами.
- Проверка целостности, механизм пробного восстановления в отдельный PostgreSQL без сети, CLI-экспорт только в новый каталог. Нет кнопки восстановления поверх рабочего чата.
- **На рабочем VPS бэкапы ещё не включены.** Нужны отдельный сохранённый пароль шифрования, установка службы, проверка прав каталога управления, ресурсов и фактического восстановления PostgreSQL. Ручной OAuth-токен не считается бессрочным; автоматическое его продление пока не реализовано.

## Обновление и проверки

- Сделать резервные копии БД/вложений до обновления. Для версии после v0.10.0 добавлена миграция 025; автоматического отката схемы нет.
- Runtime для миниатюр требует FFmpeg, Poppler и prlimit. Бэкап-служба устанавливается отдельно, не внутри веб-контейнера; инструкции — docs/backups.md.
- Go-тесты и сборка, 42 web-теста с jsdom без пропусков, 13 Python-тестов с реальным restic roundtrip. Интеграционные проверки семей и прочтений ранее выполнены на отдельной PostgreSQL.
- Синтетическая копия через ограниченный токен Яндекс Диска загружена, полностью проверена и восстановлена с побайтным сравнением; тестовые облачные объекты удалены.
- Linux/systemd и фактический PostgreSQL restore drill бэкап-службы на VPS ещё требуют приёмки. Визуальная проверка физических Android/Safari не заменяется DOM-тестами.
- Публикация этого релиза **не обновляет сервер**. Последняя зафиксированная версия VPS — chatfamily-app:20260917-no-family, схема 025.
- Новый APK к релизу не прилагается. Web-доработки доступны удалённой оболочке после обновления сервера; нативное управление кэшем требует ранее подготовленной оболочки с deviceStorage capability.

## Ограничения

- Huawei Push Kit, треды и отдельный раздел «Непрочитанные» отложены.
- История и дела пока без серверной пагинации; повторения/напоминания дел и журнал аудита всех административных действий остаются в плане.
- Общий загрузчик конфигурации приложения не переведён на settings.local.json: основной сервер использует окружение/существующий Compose, отдельный backup worker читает свой раздел этого файла.
