21 сентября 2026 года. Почта и восстановление доступа, Android-виджет,
уведомления и компактный интерфейс сообщений.

## Android 0.7.0

- Виджет **«Семья сегодня»**: закреплённая семья для каждого экземпляра,
  сегодняшние и просроченные дела, незавершённые покупки, фильтр «Назначенные мне».
- Нажатие открывает карточку; «＋ Дело» / «＋ Покупка» — форму семейной записи.
  Размер изменяется, доступны светлая/тёмная системные темы и RU/EN.
- Ручное и фоновое обновление через WorkManager, время последней загрузки,
  ограниченный кэш. Google Play Services не требуются; точное время обновления
  в фоне зависит от Android/EMUI. Выход/смена аккаунта очищают данные и привязки.
- Новый значок «Диалог» индиго; внешние HTTP/HTTPS-ссылки открываются браузером,
  без ослабления HTTPS-ограничений внутреннего WebView.
- Сохранены входящие вложения через «Поделиться», проверка обновлений,
  ограничение кэша и общий счётчик непрочитанных на поддерживаемых лаунчерах.

[Скачать Android 0.7.0, code 8](https://www.chatfamily.site/downloads/android/chatfamily-8.apk).
**Тестовая debug-сборка**, подпись совпадает с опубликованной 0.6.0.

После установки открыть ChatFamily, затем добавить виджет через меню рабочего стола.

## Почта и восстановление доступа

- Отдельная SMTP-панель администратора приложения, проверка подключения тестовым письмом.
- Сброс пароля по одноразовой ссылке, подтверждение адреса при новых регистрациях
  и регистрации по приглашению. Существующие пользователи не блокируются.
- После сброса отзываются сессии и push-подписки; пароль в письме не передаётся.
- Ручная повторная отправка с ограничением частоты. Долговечной очереди
  и автоматических повторных отправок нет.
- Секреты SMTP остаются в host-only настройках. Приложение получает только Unix socket,
  а не файл с ключами бэкапов и остальными секретами. Требуется TLS/STARTTLS.

Сервис установлен на рабочем сервере, **отправка и подтверждение регистрации пока
выключены**: администратору нужно настроить SMTP, получить тестовое письмо и включить
нужные функции. Доставка реальных писем ещё не проверена.

## Сообщения и интерфейс

- Уведомление открывает конкретное сообщение, включая старую историю и вход заново.
  Исправлены заголовок отправителя и повторяющийся текст web push.
- Безопасные HTTP(S)-ссылки и компактный текстовый предпросмотр с защитой серверных
  запросов к внутренним адресам; произвольный HTML сайтов не вставляется в чат.
- Имя, время, галочки и сокращённый счётчик прочтений объединены в заголовке сообщения.
- На телефоне действия доступны по удержанию сообщения в нижней панели;
  на компьютере — при наведении/фокусе или через контекстное меню.
- Общий счётчик непрочитанных на иконке: Web Badging API и Android, с учётом
  возможностей ОС/лаунчера. Отдельный раздел «Непрочитанные» не добавлялся.
- Управление межсемейными чатами перенесено в компактное меню «…».
- Новый web-значок. На iPhone существующий значок PWA может потребовать повторного
  добавления приложения на домашний экран; это не удаляет серверную переписку.

## Развёртывание и проверки

Сервер обновлён 2026-09-21: `chatfamily-app:20260921-widget-mail`.
Применена аддитивная миграция **032_email_actions.sql**. До обновления сохранены
проверенные копии БД/вложений/конфигурации и предыдущий образ. Бэкапы в 02:30
Europe/Moscow, SSH по ключу и сеть/MTU не менялись.

Проверены Go-тесты и vet, изолированная PostgreSQL, 102 web-теста без пропусков,
Android sync/assembleDebug/testDebugUnitTest/lintDebug (0 ошибок lint),
Linux-тесты контроллеров, HTTPS, байты ресурсов/бинарника, схема, доступ к API,
состояние контейнеров и изоляция секретов. APK проверен по подписи, размеру и SHA-256
после скачивания по HTTPS; описание обновления опубликовано последним.

Не завершена физическая приёмка iPhone/Android/EMUI: установка поверх старого APK,
виджет в реальном лаунчере, фоновые ограничения, доставка push и настоящих писем.
Huawei Push Kit, треды и повторяющиеся задачи остаются отложенными.

При откате не восстанавливать старую БД поверх новых сообщений. Старый образ
не применяет новую политику подтверждения регистрации: после её включения откат
требует закрытия регистрации и отдельного согласования.
