# Значок ChatFamily

Выбран вариант «Диалог», цвет индиго `#4A4B88`, белый знак из двух связанных реплик.
Web-ресурсы и APK 0.7.0 опубликованы 2026-09-21.

Редактируемый источник: `assets/branding/dialog-mark.svg`. Это векторная отрисовка
согласованного эскиза. `deploy/build-branding.mjs` с библиотекой sharp экспортирует
web PNG 192/512, SVG, прозрачный монохромный badge и Android VectorDrawable.
Запуск: `node deploy/build-branding.mjs`; sharp должен быть доступен через Node/NODE_PATH.
Текст в знак не встроен; поля сохраняют рисунок при маскировании лаунчером.

Web: favicon, apple-touch-icon, manifest, экран входа и push icon/badge.
Android: `ic_chatfamily` — значок приложения; `ic_stat_chat` — белый знак уведомления
без цветного фона. Цвет и представление уведомления определяет ОС.
Старый `web/icon-1254.png` сохранён для совместимости со старыми ссылками.

Для Android нужна установка опубликованного APK 0.7.0/code 8.
Уже установленная PWA может сохранять прежний значок до обновления системой
или повторного добавления на домашний экран. Проверить реальные iOS/Android,
маски лаунчера и маленькие уведомления; эмуляция браузера это не заменяет.
