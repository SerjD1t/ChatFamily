# Вставка в сообщение

Опубликовано на сервере 2026-09-18, runtime `chatfamily-app:20260918-media-settings`.

- На компьютере: Ctrl+V/Cmd+V в поле сообщения; на телефоне — системная команда
  «Вставить». Если ОС передала файл/изображение, он добавляется к вложениям.
- Дополнительно: долгое нажатие отправки → «Вставить из буфера».
  Браузер может запросить разрешение или подтверждение вставки.
- Текст остаётся текстом; HTML не исполняется, ссылки не скачиваются автоматически.
- До отправки видны имена файлов и крестики удаления. Ничего не загружается
  на сервер до явного нажатия отправки. Можно добавить несколько объектов.
- Лимиты черновика: 10 файлов, 25 МиБ на файл, 100 МиБ суммарно; сервер может
  дополнительно ограничить размер. Черновики вложений отдельны для каждого чата,
  хранятся в памяти страницы и теряются при перезагрузке/выходе.

## Совместимость

Общий web-код применяется на desktop, iPhone/Safari, Android-браузере и Capacitor.
Это не гарантия получения любого объекта из любого приложения: доступные MIME-типы
определяет ОС/браузер/источник. Скопированный путь, content URI или закрытый формат
не равнозначен доступному файлу. Нативный Android clipboard-мост не добавлен.
Если файл не передаётся, используйте «Вложить файл» или Android «Поделиться».
Программное чтение буфера без действия пользователя отсутствует.

Документация платформы: [событие вставки](https://developer.mozilla.org/en-US/docs/Web/API/ClipboardEvent/clipboardData),
[ограничения Clipboard API](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API).

Перед объявлением поддержки конкретного устройства проверить фото/скриншот,
PDF из файлового менеджера, текст/ссылку, отказ в доступе, смешанное содержимое,
смену чата во время запроса разрешения. Физические Safari/Android ещё не проверены.
