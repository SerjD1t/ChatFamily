# План развития

## Ближайшая итерация: сообщения и удобство работы с чатами

- Добавить статусы сообщений: «отправлено», «доставлено» и «прочитано». Статус должен быть виден отправителю и обновляться в реальном времени.
- Добавить карточку пользователя. Она открывается при нажатии на имя пользователя и показывает доступные сведения о нём.
- Проверить и доработать загрузку истории чата: первоначально и при подгрузке запрашивать только последние _N_ сообщений, а не всю историю. Предусмотреть постраничную загрузку более ранних сообщений.
- Сохранять открытую беседу при выходе пользователя и восстанавливать её после следующего входа, если пользователь всё ещё является её участником.
