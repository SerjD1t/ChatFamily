# План развития

## Упрощение прав — развёрнуто 2026-09-18

- Сообщения, вложения, изменение и удаление своих сообщений — базовые возможности
  всех участников доступного чата, без отдельных флагов. Старые ограничения этих
  действий игнорируются; семейное администрирование определяется ролью.
- Приглашения не предоставляют системные права; назначение администратора семьи
  доступно владельцу/администратору приложения. Изменение сообщений требует членства.

## Последние обновления

- Развёрнуто 2026-09-18: сортировка личных диалогов по последнему сообщению
  с обновлением открытого списка; исключение автора реакции из web/Android push
  на всех его устройствах, без отключения синхронизации реакции.

- Быстрый выбор срока и исполнителя прямо в карточке; список семьи без поиска,
  сохранение комментария/DOM, контроль версии и ошибок. 57 web-тестов и 8 сценариев
  Chromium пройдены; web развёрнут 2026-09-18. Остаётся ручная приёмка Safari/Android.

## Выполнено после v0.12.0

- Смена области существующего дела/покупки в редакторе: автор, подтверждение,
  выбор своей семьи, сохранение истории и снятие исполнителя при переносе в личное.
  Серверные права/версия и сценарии интерфейса проверены; Go/web развёрнуты вместе 2026-09-18.

## Выполнено в коде v0.12.0

- Личная автоматизация: ежедневный отчёт по текущим личным и назначенным семейным
  делам/покупкам, время и часовой пояс, серверная отправка в диалог с собой.
  Миграция 027; транзакционная PostgreSQL-приёмка пройдена в изолированной БД.

- Android 0.5.0: проверка версии раз в сутки/вручную, подтверждённая загрузка и
  системная установка APK с VPS. Debug-сборки разрешены, подпись должна совпадать.
  Сборка и автотесты пройдены; физические Android/EMUI ещё не проверены.

- Личные дела и покупки в общем разделе; доступны без
  семьи, только владельцу. Общая таблица, миграция 026, отдельный личный API.

- Исправлено сохранение личного контекста при смене семьи и выбор её общего чата.
- Устранены причины горизонтального переполнения чата и автоувеличения полей на iPhone.
- Отдельный экран пользователей приложения; исправлен повторный вход в чат на телефоне.

Фактическое развёртывание — в docs/operations.md, не определяется наличием тега.

- Новый интерфейс семейного пространства: выбор семьи, глобальные личные диалоги и профиль текущего пользователя.
- Семейные разделы «Дети» и «Бабушки и дедушки» на основе категорий участников.
- Общий список покупок с плановой датой, выполнением и счётчиком «на сегодня / всего».
- Личный диалог с самим собой с пометкой «Вы».

  клавиатура и возврат после закрытия без изменения масштаба.

- Использовать семейные категории для адресных уведомлений и правил доступа к будущим функциям.
- Добавить серверную пагинацию общего справочника пользователей, дел/покупок и истории при росте объёма данных. В новом управлении всеми семьями списки семей/участников/кандидатов уже имеют серверные страницы по 25 записей.
- После отдельного согласования расширить покупки количеством/ценой, дела — повторениями и напоминаниями.
- Добавить журнал аудита административных действий: изменения ролей, категорий, прав, приглашений и настроек.
- Дополнить включённые резервные копии внешним мониторингом пропущенных запусков и подтвердить независимое хранение ключа восстановления. См. [резервные копии](backups.md). S3 пока не требуется.
- Добавить закреплённые сообщения в группах.
- Добавить безопасный Markdown для сообщений. Базовые скины и палитры реализованы; расширение каталога — по запросу.
