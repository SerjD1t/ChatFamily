# Уведомления и предпросмотр ссылок

Развёрнуто 2026-09-22: после успешной отправки в чате,
открытом по уведомлению, сбрасывается привязка `around` и загружается последний
участок истории. Существующие DOM-узлы сохраняются, прокрутка переходит к ответу.
При ошибке отправки привязка и черновик не сбрасываются.

Серверная и web-доработка развёрнута 2026-09-21 после v0.13.0.
Нативная обработка внешних HTTP-ссылок включена в опубликованный 2026-09-21 APK 0.7.0.

## Уведомления

Web push содержит идентификаторы чата и сообщения. Нажатие фокусирует открытый
клиент и передаёт цель либо запускает клиент со ссылкой. После входа цель сохраняется.
Для сообщения вне последних 50 загружается ограниченная страница истории с проверкой
членства. Сообщение прокручивается в видимую область и кратко подсвечивается.
«К последним сообщениям» возвращает из просмотра старого участка; realtime-обновления
не подменяют этот участок последними сообщениями и не отмечают невидимое прочитанным.
Если сообщение очищено или доступ отозван, показывается ошибка, без обхода прав.

В личном push заголовок — отправитель, а не название диалога со стороны отправителя
(которое раньше могло показывать получателю его собственное имя). В групповом —
автор и чат. Текст ограничен, имя не дублируется в теле. Имя PWA в manifest — ChatFamily.
Системная строка iOS `from …` не добавляется payload приложения и не скрывается им;
имя уже установленного ярлыка может остаться прежним. Проверить на устройстве до
любого удаления/повторной установки, чтобы не потерять локальные настройки.

FCM сохраняет общий текст без содержимого переписки и теперь передаёт messageID.
Старые уведомления без messageID по-прежнему открывают чат. Huawei без GMS это
не добавляет доставку push; Huawei Push Kit остаётся отложенным.

## Ссылки

HTTP(S)-адреса в тексте становятся ссылками. Первая ссылка сообщения получает
компактную карточку: домен, заголовок и краткое описание. Если сайт не отвечает,
не отдаёт HTML или отказывается от предпросмотра, обычная ссылка остаётся рабочей.
Удалённые картинки/iframe/script не встраиваются. Cookies пользователя стороннему
сайту не передаются; метаданные запрашивает VPS, которому сайт видит сетевой адрес.

Сервер запрещает credentials в URL, нестандартные порты, локальные/служебные IP,
IPv6 transition-диапазоны и HTTPS→HTTP редиректы. DNS проверяется перед фактическим
подключением с фиксацией проверенного IP; редиректы проходят те же ограничения.
Есть лимиты времени, размера, числа редиректов и параллельных запросов. Полученные
строки выводятся как текст, не HTML. Кэш интерфейса ограничен, обновление карточки
сохраняет положение истории. Предпросмотр не расходует лимит запросов входа/сброса.

В браузере ссылка открывается отдельно, с `noopener noreferrer`. Android использует
внешний браузер; опубликованная **0.7.0 / versionCode 8** добавляет HTTP к ранее поддержанному
HTTPS. Внутри WebView не расширены allowlist и доступ к нативному мосту, mixed content
не включён. Для HTTPS и переходов из push достаточно обновления сервера/web;
для внешних HTTP-ссылок старого Android-клиента потребуется новый APK.

Ручная приёмка: iPhone/PWA и Android, холодный/открытый клиент, вход после уведомления,
старое/удалённое сообщение, отозванное членство, две быстрые смены цели, ссылки
HTTP/HTTPS, отсутствие сети, длинный URL и сохранение прокрутки/черновика.
