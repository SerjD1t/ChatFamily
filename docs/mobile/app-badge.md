# Непрочитанные на иконке приложения

Локальная доработка после v0.13.0, Android 0.6.0 / versionCode 6.
Сервер опубликован 2026-09-19 (`20260919-message-sheet`); APK 0.6.0 пока локальный,
на сервере остаётся APK 0.5.0. Миграции не нужны.

На иконку передаётся одно число: сумма непрочитанных **сообщений** всех доступных
личных, семейных, независимых и межсемейных чатов. Выбранная семья не ограничивает
сумму. Собственные, удалённые сообщения, архивные/недоступные чаты не учитываются.
Доставка не равна прочтению; дела и покупки не включаются. Ноль очищает значок.

## Обновление

- `GET /api/v1/me/unread`: текущая сессия, private/no-store, без идентификаторов
  чужого пользователя в запросе. Ошибка БД возвращает 503, а не ложный ноль.
- Активный клиент обновляет значение при загрузке/изменениях чатов и прочтении,
  восстановлении WebSocket, сети и возврате приложения на экран. Запросы
  сериализованы, при выходе ожидающий ответ не возвращает старое число.
- В установленном веб-приложении используется Badging API. При обычном push
  service worker запрашивает актуальную сумму, не увеличивает прошлое значение.
  Ошибка сети/отсутствие API не мешает видимому уведомлению.
- Android: capability `appBadge`, bridgeVersion 4, метод `PushEnvironment.setBadge`.
  Тихое сводное уведомление несёт абсолютное число через `setNumber`; FCM передаёт
  тот же итог через `notification_count`. Общий tag заменяет прошлое уведомление
  сообщения, а не складывает несколько одинаковых итогов. Реакции и загрузки
  используют каналы без badge. Старые APK не вызывают отсутствующий метод.

## Ограничения платформ

Android связывает значок с уведомлениями: при ненулевом счётчике присутствует тихое
сводное уведомление. Лаунчер может показывать число, точку или вообще не поддерживать
badge; удаление уведомления/системные настройки могут убрать значок независимо от
прочтения. Системные предпочтения не переопределяются. Ранее созданные каналы могут
сохранить пользовательские настройки. Нужна проверка конкретного лаунчера.

iPhone: веб-приложение должно быть добавлено на домашний экран, iOS 16.4+,
разрешены уведомления/значки. Обычная вкладка Safari не заменяет установленное приложение.

Закрытый клиент **не гарантирует немедленное уменьшение** после прочтения на другом
устройстве: оно уточняется при следующем уведомлении или открытии. Отдельные скрытые
push ради счётчика не отправляются. Push может задерживаться, поэтому в фоне число
может временно устареть. Huawei/EMUI без GMS не получает FCM; Huawei Push Kit остаётся
отложенным, здесь обновление возможно при работе/возврате приложения.

Публикация: сначала сервер (API, web и FCM), затем APK 0.6.0 с прежней подписью.
Не публиковать APK/latest.json без отдельного запроса. Проверить на физических
iPhone/Android/EMUI: две семьи, два устройства, прочтение части/всех сообщений,
выход/смена аккаунта, запрет уведомлений, отсутствие сети, число/точку, очистку нуля.

Официальные ограничения: [Android badges](https://developer.android.com/develop/ui/views/notifications/badges),
[FCM AndroidNotification](https://firebase.google.com/docs/reference/fcm/rest/v1/projects.messages#AndroidNotification),
[WebKit Badging API](https://webkit.org/blog/14112/badging-for-home-screen-web-apps/).
