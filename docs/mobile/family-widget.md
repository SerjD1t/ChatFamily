# Android: «Семья сегодня»

## Опубликовано 2026-09-25 — APK 0.9.2 / код 13

В настройках каждого экземпляра добавлены часы, день недели и дата (по умолчанию
выключены), прозрачность фона 0–100% и цвет текста: по теме Android, тёмный или
светлый. Прозрачность меняет только фон, не текст и кнопки. Существующий вид
сохраняется до изменения настроек. Подбирайте цвет текста под обои.

Используется системный TextClock: время/дата устройства, формат времени 12/24 часа;
часы не зависят от запросов сводки и WorkManager. Поддержка RemoteViews описана
в [Android API](https://developer.android.com/reference/android/widget/RemoteViews).
Часы занимают место над названием семьи, число строк сводки уменьшается.
При слишком малой высоте часы временно скрываются, чтобы сохранить управление
и непрочитанные чаты; для восстановления увеличьте виджет.

Нужен новый APK. Сервер обновлён, [APK опубликован](https://www.chatfamily.site/downloads/android/chatfamily-13.apk).
Подпись прежняя, тестовая debug-сборка. Ручная приёмка: два экземпляра,
прозрачность 0/50/100%, светлые/тёмные обои, маленький размер и крупный шрифт,
смена минуты/даты/часового пояса, Huawei без GMS.

## Опубликовано 2026-09-23 — APK 0.9.1 / код 12

- Покупку закрепляют **булавкой в её карточке ChatFamily**, на любом устройстве.
  Это личная настройка пользователя, не изменение покупки для всей семьи.
  Доступно любому действующему участнику для текущих семейных покупок, до трёх
  на пользователя/семью. Повторное нажатие снимает закрепление. Личные записи,
  дела, завершённые и архивные покупки не закрепляются.
- Виджеты выбранной семьи автоматически используют эти закрепления вместо сводки;
  без активных закреплений возвращается общая сводка. Выбор покупок в настройках
  Android удалён. На маленьком виджете остаются первые названия; весь список
  открывается нажатием. Завершение/архив скрывают покупку, перенос в личные
  удаляет её закрепления. Выход из семьи удаляет личные закрепления этой семьи.
- Старые локальные закрепления версии 0.9.0 не превращаются молча в общие для
  всех устройств: после обновления покупку нужно один раз закрепить в карточке.
- Непрочитанные чаты — горизонтальный ряд до пяти кружков по ширине (обычно 3–5),
  в порядке последнего сообщения. Аватар собеседника или пиктограмма группы;
  без изображения — инициалы. На значке счётчик (99+ для больших значений),
  под ним краткое название, для accessibility — полное название и точное число.
  Общий счётчик по-прежнему включает все чаты аккаунта. Нажатие открывает диалог,
  не помечая сообщения прочитанными до обычной проверки видимости.
- Ряд чатов не скрывается из-за малой высоты; при совсем маленьком виджете
  семейная сводка скрывается, заголовок остаётся переходом к списку.
  Покупка без чек-листа показывает «Открыть покупку», а не «Куплено 0 из 0».
- Миниатюры загружаются только с разрешённого пути своего HTTPS-origin, без
  редиректов, с лимитом объёма/разрешения и проверкой смены сессии; кэш содержит
  только маленькие изображения, не cookies. Ошибка картинки оставляет инициалы.

Сервер: `PUT /api/v1/families/{familyID}/needs/{itemID}/widget-pin`, тело
`{"pinned":true|false}`. Только собственные закрепления; изменения идемпотентны,
лимит сериализован. `widgetPinned` в карточке; `savedPins=true` в API виджета
включает серверный выбор. Старые APK сохраняют прежний API с локальными `pins`.
Миграция **035_widget_purchase_pins.sql** добавляет отдельную таблицу, не меняя
версию/историю общей покупки. Сервер/web переносить вместе после резервной копии,
затем APK. При откате таблицу не удалять. Сервер/web и APK опубликованы;
физическая приёмка ещё не выполнена.

## Опубликованная версия 0.9.0

Опубликована **0.9.0 / код 11**, 2026-09-22: настройка «Показывать
непрочитанные чаты аккаунта» (по умолчанию выключена). Включает все доступные
личные, групповые и семейные чаты независимо от выбранной семьи. Только название
и число непрочитанных, без текста сообщений. Порядок — последнее сообщение;
API возвращает до четырёх чатов и общий счётчик, виджет показывает до двух строк
по доступной высоте. Для появления списка и переходов нужны новые сервер/web и APK.
Обновляется при событиях в открытом приложении, вручную и через WorkManager;
мгновенное фоновое обновление Android не гарантирует. Чтение списка не ставит
отметки прочтения. Доступ при открытии проверяется заново.
Семья по-прежнему выбирается для настройки экземпляра и его дел/покупок, но не
фильтрует чаты. Старый сервер не показывает новый блок, старый APK не затрагивается.
Добавлен режим «Закреплённые покупки»: выбрать от одной до трёх текущих покупок
выбранной семьи вместо общей сводки. В настройке доступны первые 200 покупок.
Чек-лист формируется в карточке покупки; в виджете видны название, число купленных
пунктов и оставшиеся пункты по доступной высоте. Нажатие названия открывает весь список;
при маленьком размере виджета остаются названия и счётчики. Завершённые/архивные или
перенесённые из семьи покупки исчезают после обновления. Личные покупки не закрепляются.

Нажатие пункта сохраняет явное состояние с версией записи через сервер. До подтверждения
отметка не меняется, при ошибке появляется предложение обновить и повторить; автоматической
очереди повторов нет. Когда всё куплено, отдельная строка предлагает завершение покупки.
Изменения другого участника не перезаписываются; cookie/аккаунт и поколение настроек
проверяются. Для режима требуются миграция 034, новый сервер/web и APK вместе.

Исправление, подготовленное в 0.7.1 / код 9 и опубликованное в 0.9.0: экран
настройки проверяет текущую WebView cookie-сессию напрямую через существующий API,
даже если web-мост не сохранил идентификатор аккаунта. При возврате проверка повторяется;
есть кнопки открытия приложения и ручного повтора. Смена cookie/поколения состояния
отклоняет устаревший ответ; фоновые запросы остаются привязаны к ожидаемому аккаунту.
Для этого исправления достаточно обновления APK, сервер менять не требуется.

Статус: сервер, web и тестовый APK **0.9.0 / код 11** опубликованы 2026-09-22; миграция 034 применена.
[Скачать APK](https://www.chatfamily.site/downloads/android/chatfamily-11.apk).
Для появления виджета нужно установить обновление и открыть ChatFamily.
Виджет не зависит от Firebase, Google Play Services или Huawei Push Kit.

## Как использовать

1. После обновления сервера и APK открыть ChatFamily и войти в аккаунт.
2. На рабочем столе Android открыть список виджетов, выбрать ChatFamily → «Семья сегодня».
3. Выбрать семью и при необходимости «Только дела, назначенные мне».
4. Менять настройки через «⋯», обновлять вручную через «↻».

Каждый экземпляр хранит собственную выбранную семью и фильтр. Обычное переключение
пространства внутри приложения их не меняет. Виджет содержит:

- число дел на сегодня и просроченных; в строках сначала просроченные, затем сегодняшние;
- исполнителя и дату, если они указаны;
- все невыполненные покупки этой семьи, в том числе без срока;
- переход по строке в карточку; «＋ Дело» / «＋ Покупка» открывают форму, не создают запись;
- время последней загрузки и обозначение сохранённых данных при ошибке сети.

Будущие и недатированные дела, завершённые/архивные записи и личные данные не выводятся.
Фильтр исполнителя применяется к делам; покупки всегда общие. Счётчики считают все
подходящие записи; сервер передаёт до четырёх строк каждого типа. При уменьшении
виджета строк меньше, в минимальном размере остаются счётчики и кнопки.
По заголовку/счётчикам открывается обычный раздел «Дела и покупки» выбранной семьи;
там также остаются личные записи пользователя и его фильтры.

Язык RU/EN и светлая/тёмная палитра виджета следуют настройкам Android, а не web-профиля.
Рабочий стол может быть виден другим людям: названия записей там не скрыты.

## Обновление и безопасность

WorkManager запрашивает сводку примерно раз в 30 минут, а также по ручному обновлению,
после открытия приложения и изменений семейных записей в активном клиенте.
Точное время не гарантируется: Android/EMUI могут задерживать фоновые задания.
После принудительной остановки приложения нужно открыть его снова. Это не push.

Кэш приватный, ограничен последней сводкой на виджет. При очередной проверке снимок
старше суток удаляется; при остановленном процессе уже нарисованная лаунчером картинка
может сохраняться до следующего обновления. Проверяйте дату загрузки.
Выход и смена аккаунта очищают данные и конфигурации всех экземпляров. После нового
входа нужно заново выбрать семьи. HTTP 401 также очищает привязки; 403 убирает сводку
соответствующей семьи. Отзыв доступа обнаруживается при следующем запросе, не мгновенно.

Только фиксированный HTTPS-origin, стандартная проверка TLS, без редиректов.
Используется существующая cookie-сессия WebView: дополнительный токен не сохраняется.
`X-Expected-User` и идентификатор аккаунта в ответе защищают от смены cookie; поколение
локального состояния отклоняет запоздавшие ответы после выхода/перенастройки.
Администратор приложения без членства в семье не получает сводку этой семьи.

## Реализация и совместимость

- Go: `GET /api/v1/mobile/widget`; без `familyId` — минимальный список своих семей,
  с `familyId`, `mine`, `timezone` — сводка. `Cache-Control: no-store`.
- `apps/mobile/android/.../widget/`: AppWidgetProvider, RemoteViews, конфигурация,
  WorkManager, приватный кэш и Capacitor-плагин FamilyWidget.
- `web/mobile/family-widget.js`: capability gate, синхронизация аккаунта и действия.
- `web/family-needs.js`: безопасное открытие карточки/добавления указанной семьи.

Старые APK без capability `familyWidget` работают без виджета; web-браузер не вызывает
нативный мост. Новый APK со старым сервером не получает сводку и предлагает обновить сервер.
Для исходной сводки миграция не требовалась; чек-листы требуют 034.
Публикация сервера/APK и Git — только отдельным запросом.

## Ручная приёмка

Автотесты проверяют фильтры/счётчики, изоляцию БД, удалённое членство, привязку аккаунта,
web-переходы, срок кэша и число строк. Сборка и lint не заменяют тест на устройстве:

- добавить два виджета разных семей; переключить семью в приложении;
- проверить маленький/большой размер, крупный системный шрифт, RU/EN, тёмную тему;
- открыть карточку и обе формы добавления из закрытого и открытого приложения;
- выйти во время обновления, войти другим аккаунтом: старые сведения не возвращаются;
- отключить сеть, восстановить её, отозвать членство; проверить сообщения и ручное обновление;
- на Huawei без GMS проверить ручное обновление и поведение фоновых заданий EMUI.

Физическая приёмка на телефоне ещё не выполнена.
