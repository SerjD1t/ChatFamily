# Android: «Семья сегодня»

Статус: сервер, web и тестовый APK **0.7.0 / код 8** опубликованы 2026-09-21.
[Скачать APK](https://www.chatfamily.site/downloads/android/chatfamily-8.apk).
Для появления виджета нужно установить обновление и открыть ChatFamily.
Виджет не зависит от Firebase, Google Play Services или Huawei Push Kit.

## Как использовать

1. После обновления сервера и APK открыть ChatFamily и войти в аккаунт.
2. На рабочем столе Android открыть список виджетов, выбрать ChatFamily → «Семья сегодня».
3. Выбрать семью и при необходимости «Только дела, назначенные мне».
4. Менять настройки через «⋯», обновлять вручную через «↻».

Каждый экземпляр хранит собственную выбранную семью и фильтр. Обычное переключение
пространства внутри приложения их не меняет. Виджет содержит:

- число дел на сегодня и просроченных; в строках сначала просроченные, затем сегодняшние;
- исполнителя и дату, если они указаны;
- все невыполненные покупки этой семьи, в том числе без срока;
- переход по строке в карточку; «＋ Дело» / «＋ Покупка» открывают форму, не создают запись;
- время последней загрузки и обозначение сохранённых данных при ошибке сети.

Будущие и недатированные дела, завершённые/архивные записи и личные данные не выводятся.
Фильтр исполнителя применяется к делам; покупки всегда общие. Счётчики считают все
подходящие записи; сервер передаёт до четырёх строк каждого типа. При уменьшении
виджета строк меньше, в минимальном размере остаются счётчики и кнопки.
По заголовку/счётчикам открывается обычный раздел «Дела и покупки» выбранной семьи;
там также остаются личные записи пользователя и его фильтры.

Язык RU/EN и светлая/тёмная палитра виджета следуют настройкам Android, а не web-профиля.
Рабочий стол может быть виден другим людям: названия записей там не скрыты.

## Обновление и безопасность

WorkManager запрашивает сводку примерно раз в 30 минут, а также по ручному обновлению,
после открытия приложения и изменений семейных записей в активном клиенте.
Точное время не гарантируется: Android/EMUI могут задерживать фоновые задания.
После принудительной остановки приложения нужно открыть его снова. Это не push.

Кэш приватный, ограничен последней сводкой на виджет. При очередной проверке снимок
старше суток удаляется; при остановленном процессе уже нарисованная лаунчером картинка
может сохраняться до следующего обновления. Проверяйте дату загрузки.
Выход и смена аккаунта очищают данные и конфигурации всех экземпляров. После нового
входа нужно заново выбрать семьи. HTTP 401 также очищает привязки; 403 убирает сводку
соответствующей семьи. Отзыв доступа обнаруживается при следующем запросе, не мгновенно.

Только фиксированный HTTPS-origin, стандартная проверка TLS, без редиректов.
Используется существующая cookie-сессия WebView: дополнительный токен не сохраняется.
`X-Expected-User` и идентификатор аккаунта в ответе защищают от смены cookie; поколение
локального состояния отклоняет запоздавшие ответы после выхода/перенастройки.
Администратор приложения без членства в семье не получает сводку этой семьи.

## Реализация и совместимость

- Go: `GET /api/v1/mobile/widget`; без `familyId` — минимальный список своих семей,
  с `familyId`, `mine`, `timezone` — сводка. `Cache-Control: no-store`.
- `apps/mobile/android/.../widget/`: AppWidgetProvider, RemoteViews, конфигурация,
  WorkManager, приватный кэш и Capacitor-плагин FamilyWidget.
- `web/mobile/family-widget.js`: capability gate, синхронизация аккаунта и действия.
- `web/family-needs.js`: безопасное открытие карточки/добавления указанной семьи.

Старые APK без capability `familyWidget` работают без виджета; web-браузер не вызывает
нативный мост. Новый APK со старым сервером не получает сводку и предлагает обновить сервер.
Для этого функционала новая миграция БД не нужна; другие локальные изменения требуют 032.
Публикация сервера/APK и Git — только отдельным запросом.

## Ручная приёмка

Автотесты проверяют фильтры/счётчики, изоляцию БД, удалённое членство, привязку аккаунта,
web-переходы, срок кэша и число строк. Сборка и lint не заменяют тест на устройстве:

- добавить два виджета разных семей; переключить семью в приложении;
- проверить маленький/большой размер, крупный системный шрифт, RU/EN, тёмную тему;
- открыть карточку и обе формы добавления из закрытого и открытого приложения;
- выйти во время обновления, войти другим аккаунтом: старые сведения не возвращаются;
- отключить сеть, восстановить её, отозвать членство; проверить сообщения и ручное обновление;
- на Huawei без GMS проверить ручное обновление и поведение фоновых заданий EMUI.

Физическая приёмка на телефоне ещё не выполнена.
