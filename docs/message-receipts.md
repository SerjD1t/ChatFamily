# Кто прочитал сообщение

Включено в v0.11.0. Впервые развёрнуто 2026-09-17: runtime chatfamily-app:20260917-receipt-details. Интеграционные проверки пройдены на отдельной одноразовой PostgreSQL до обновления; сама доработка прочтений не добавляла миграцию. Текущее состояние сервера и миграции указаны в [эксплуатации](operations.md).

Доработка развёрнута 2026-09-21: имя автора, время и галочки собраны в заголовке сообщения; отдельной нижней служебной строки нет. В группах счётчик сокращён до `X/Y`; полная подпись «Прочитали X из Y» остаётся в подсказке и доступном имени кнопки. В личном диалоге счётчика нет. При нехватке ширины заголовок переносится; длинное имя не обрезается. В последовательных сообщениях имя сохраняется, повторный аватар скрывается.

Нажмите галочки своего сообщения: на компьютере откроется диалог, на телефоне — нижняя панель. Подробности доступны тем же нажатием; правила доступа, подсчёта и подтверждения прочтения не менялись.

В окне три списка: прочитали; доставлено, не прочитано; не доставлено. Для каждого получателя показаны имеющиеся серверные отметки времени доставки и прочтения, в часовом поясе устройства смотрящего. В семейном чате используются имя/семейный статус, в остальных — отображаемое имя с фамилией. Email не выдаётся.

Миграция 025, развёрнутая 2026-09-17, меняет семейную подпись на «Статус (Имя)», без статуса — только имя. Формат общий для истории, поиска и списка прочтения. Ранее отправленные цитаты, сохранённые в тексте сообщений, не переписываются.

Используется **текущий состав чата**, без автора. Новые участники входят в расчёт старых сообщений, выбывшие исключаются; деактивированный аккаунт остаётся в расчёте, пока остаётся участником. Исторический список получателей не фиксируется. В диалоге с собой список пустой. Галочки по-прежнему означают: отправлено / доставлено всем / прочитано всеми; частичное прочтение видно по счётчику.

Время — первое подтверждение, принятое сервером, не гарантия внимательного чтения. Задержка сети влияет на него; старые отметки, перенесённые миграцией 018 из прежних данных, не являются точной историей просмотра каждого сообщения. Отправка ответа сама по себе не отмечает сообщения прочитанными. Логика видимости/фокуса Android в этой доработке не менялась.

Подробности доступны только автору, который остаётся участником чата. Администратор не получает обхода этого ограничения. Прямые запросы других пользователей возвращают 404 без раскрытия списка. Ответы не кэшируются. Закрытие окна защищено от запоздалых ответов; обновление списка не перерисовывает историю чата. Есть ручная кнопка обновления, обновление по статусным событиям и периодической сверке статусов активного чата.

API: GET `/api/v1/messages/{id}/receipts`; POST `/api/v1/message-statuses?details=1` возвращает сводки status/total/delivered/read для максимум 100 собственных сообщений. Без details прежний формат со строковыми статусами сохраняется. Новая миграция не нужна: используются существующие message_receipts и conversation_members.

Перед переносом нужны актуальный бинарник и web/ вместе, новый APK не требуется. Проверки: Go, JS/jsdom; PostgreSQL-сценарии в TestPostgresRepositoryRoundTrip (только отдельная тестовая БД). Вручную: Android/Safari, размер панели с клавиатурой, две сессии, частичное прочтение, изменение состава, RU/EN, темы. Проверка реального Android-подтверждения и причины жалобы на отрисовку остаётся отдельной диагностикой.
